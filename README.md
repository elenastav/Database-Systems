Project A extends and implements a relational database for a university department using PostgreSQL, including database functions for data management and retrieval, triggers for automated validation and calculations, and views for data retrieval and reporting.

Project B develops a Java application that communicates with a PostgreSQL database through JDBC, implementing database connectivity, student grade queries, and automated generation of laboratory assignments and workgroups, while analyzing and optimizing query performance using EXPLAIN ANALYZE, indexes, clustering, and different join strategies.

Tools: Java, JDBC, PostgreSQL, pgAdmin, Eclipse, SQL
